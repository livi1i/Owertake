# Работа вдвоём над OVERTAKE

## Скачать и запустить

Установите Git и Node.js 24 или новее. В терминале выполните

```powershell
git clone https://github.com/livi1i/Owertake.git
cd Owertake
npm ci
npm run dev
```

Откройте http://127.0.0.1:5178. Для Codex выберите папку Owertake как проект. Исходники интерфейса находятся в src, сервер для Timeweb в server/timeweb-api.php, схема базы в drizzle. Локальная база создаётся автоматически. Реальные записи портфолио находятся в content/approved-portfolio.json. Данные, изменяемые через админку на Timeweb, хранятся в серверной базе. Для локального просмотра реальные работы можно добавить через редактор портфолио, используя этот JSON.

## Перед началом каждой смены

```powershell
git pull --ff-only
```

Если есть свои незакоммиченные изменения, сначала сохраните их коммитом. При расхождении веток объедините изменения и разрешите конфликты в Codex. Договоритесь, кто сейчас публикует сайт.

## Сохранить изменения для второго разработчика

```powershell
npm test
npm run build
git add .
git commit -m "Описание изменений"
git push
```

Перед коммитом проверьте git diff --cached. Второй разработчик получает изменения командой git pull --ff-only. Доступ к приватному репозиторию выдаётся владельцем через Settings → Collaborators.

## Опубликовать на Timeweb

Получите у владельца существующий файл .local/timeweb-config.json и положите его по тому же пути в своей копии проекта. Передавайте его лично по защищённому каналу. В нём находятся ключи действующего развёртывания. В Git этот файл исключён.

```powershell
npm run publish:timeweb
```

Команда запускает тесты, сборку и подписанную публикацию на действующий сервер. Пользователи и заявки хранятся отдельно от релизов. После публикации проверьте https://helmerzy.tw1.ru и /api/health. Публикуйте актуальный согласованный коммит. Постоянный watcher запускается отдельной командой npm run sync:timeweb и публикует каждое изменение, поэтому для обычной работы используйте разовую публикацию.

Локальную SQLite-базу нельзя подменять серверной при обновлении кода. Контакты, цены, услуги и портфолио редактируются через админку. Подробности инфраструктуры и история публикаций находятся в TIMEWEB.md, выполненные этапы в MODERNIZATION.md.
