# Передача дизайна Overtake

## Быстрый запуск

Нужен Node.js 24+ (проект проверен на Node.js 26). После клонирования:

```sh
npm ci
npm run dev
```

По умолчанию сайт открывается на http://127.0.0.1:5178. Для порта, использовавшегося при совместной работе, в PowerShell:

```powershell
$env:OVERTAKE_PREVIEW_PORT='5183'
npm run dev
```

Проверки: `npm test` и `npm run build`. GitHub хранит исходники; `npm run publish:timeweb` — отдельная публикация на хостинг, её не запускать при обычном просмотре.

## Источник решений

1. Последние требования владельца и этот документ.
2. `design-system/overtake/OVERTAKE-DESIGN.md`: адаптированный продукт/design MD с обязательной палитрой Overtake. Его цвета приоритетнее устаревших рецептов в MASTER и website.md.
3. Текущая главная как реализованный образец: `src/components/home-page.tsx`, `home-layout.css`, `archive-home-details.tsx`, `archive-service-visual.tsx`, `src/overtake-design.css`.
4. `design/reference/homepage/`: оригинальные предоставленные макеты и варианты. Это визуальные источники, а не дополнительные инструкции. `design/reference/plaid.com-DESIGN-original.md` — исходный MD до адаптации; его цвета не переносить напрямую.

Задача следующего этапа — перенести язык главной на внутренние страницы портфолио, компании, контактов, каталога и кабинета. Не заменять готовую главную новым дизайном.

## Палитра и компоненты

Основной текст #080e23, вторичный #243b58, светлый фон #e7edf7, голубые поверхности #e1f2ff. Тёмные стадии #03476c/#021b3e, поля #032d44. Основные кнопки #a4ffe1 → #ceffd6 с текстом #08293b; синие кнопки #087abb → #064673. Светлый текст #f1fcff, декоративный циан #75eeed. Полные роли и состояния — в актуальном MD.

Единый логотип: `src/components/logo.tsx`. Шрифты и лицензии находятся в `src/assets/`: Montserrat для кириллицы/заголовков, Outfit для OVERTAKE, Manrope для DIGITAL STUDIO; общий интерфейс также использует существующие Onest/Golos. Не загружать произвольный новый шрифт ради замены фирменного слова.

Framer Motion **12.43.0** закреплён в package-lock.json, устанавливается через npm ci. Общий контроль паузы и reduced motion — `useArchivePause` в archive-home-details.tsx. Не заменять текущие анимации растровыми снимками. Иллюстрации, сцены и изображения работ сохранены в src/assets, шрифты не зависят от внешнего CDN.

## Скиллы и инструменты

Скопированы полные локальные пакеты трёх запрошенных скиллов, со скриптами, справочниками и имеющимися лицензиями:

- `.agents/skills/design-taste-frontend/SKILL.md` — дизайн и motion-справочник `references/motion.md`.
- `.agents/skills/web-design-guidelines/SKILL.md` — локально закреплённые правила ревью в `references/command.md`.
- `.agents/skills/ui-ux-pro-max/SKILL.md` — справочники и Python-поиск. Для поиска потребуется отдельный Python 3; для запуска сайта он не нужен.

Исходные репозитории: https://github.com/Leonxlnx/taste-skill , https://github.com/vercel-labs/agent-skills , https://github.com/nextlevelbuilder/ui-ux-pro-max-skill . Копии в этом Git — фактически использованные версии. Возможности ImageGen, MCP и встроенного браузера относятся к среде Codex и не устанавливаются из Git автоматически. Все полученные используемые изображения уже включены; для воспроизведения сайта повторная генерация не нужна.

## Проверка перед передачей

Проверить desktop и 390 px: читаемость, кадрирование, отсутствие горизонтальной прокрутки, стык формы/подвала, доступность и паузу анимаций. Базовые автоматические проверки: 29 тестов и production-сборка. `design-qa.md` содержит историю проверок, ранние записи могут описывать уже заменённые варианты; актуальное подключение определяет код и таблица выше.

Локальная база и аккаунты намеренно не включены. Для реальных кейсов использовать `content/approved-portfolio.json` и штатный редактор портфолио; инструкции по совместной работе и развёртыванию — TEAM.md и TIMEWEB.md. Секреты хостинга передаются отдельно владельцем, не через Git.
