# Пробное восстановление фонов 01 и 07

Метод: встроенный ImageGen, редактирование существующих PNG. Оригиналы сохранены.

- 01-hero-restored.png: 1777×885 против 1024×510. Линии визуально ровнее, но восстановление слегка меняет яркость и детали. Это не нативный 4K и не побайтовая копия.
- 07-portfolio-restored.png: 1024×1536, как оригинал. Рост разрешения не получен; массовое применение этого метода пока не обосновано.

Режим сравнения: ?background-preview=restored. По умолчанию сайт продолжает использовать оригиналы. Для проверки: главная #home, портфолио #work. Проверены десктоп главной и мобильное портфолио 390 px; левая голубая линия сохранена. Production-сборка проходит.

Запросы ImageGen: conservative high-resolution restoration, not redesign; preserve exact composition, palette, every wave and glow; remove jagged pixel steps, smooth fine antialiased contours, no sharpening halos; no new objects/text/texture. Для 01 запрошено 3840×1912, для 07 — 2560×3840, с обязательным сохранением левой serpentine cyan line. Фактические размеры указаны выше; запрошенные 4K-размеры инструмент не выдал.

Следующий этап для остальных фонов требует выбора способа после сравнения пробных вариантов. Искусственное увеличение размера файла само по себе не считается восстановлением деталей.
