# OVERTAKE

React 19 + TypeScript + Vite, Motion и компоненты официального Magic UI. Сервер совместим с Cloudflare Workers / D1; локально используется встроенный SQLite в Node 22.13+ (рекомендуется Node 24+).

## Запуск

```powershell
npm install
npm run dev
```

Сайт: http://127.0.0.1:5178. Локальные данные: `.local/overtake.sqlite`, не входят в Git.

```powershell
npm test
npm run build
```

## Доступ команды

Зарегистрируйте личный аккаунт. Для локальной разработки назначьте его администратором:

```powershell
node scripts/admin.mjs your-email@example.com
```

На размещённом сайте: зарегистрируйтесь, войдите, откройте «Профиль» и введите одноразовый ключ настройки из локального файла `.local/ADMIN-SETUP.txt`. Он хранится как серверный секрет, не входит в сборку и репозиторий. Назначение возможно только пока нет ни одного администратора. Остальные пользователи всегда регистрируются как клиенты.

## Что работает

- Адаптивный сайт: услуги, фильтруемое портфолио, процесс, FAQ, контакты.
- Реальная регистрация по почте, вход, выход, HttpOnly-сессии.
- Заявки с сайта, персональная история проектов, статусы, согласованная стоимость и сроки.
- Переписка клиента и команды с проверкой принадлежности проекта на сервере.
- Закрытый калькулятор, сохранение расчётов, экспорт клиентского предложения без себестоимости.
- Администрирование заявок, цен, портфолио, контактов и реквизитов.
- База D1 на хостинге, отдельная SQLite для локальной разработки.

## До коммерческого запуска

Добавить подтверждённые реквизиты ИП, контакты, офис, реальные кейсы, цены и утверждённую политику обработки данных. Демонстрационные концепты не являются выполненными клиентскими работами. Подключить почтовый провайдер для подтверждения адреса и восстановления пароля. Загрузка документов, счета/оплата, файловые вложения, электронное подписание и бонусная программа пока не реализованы; интерфейс документов обозначает это явно. Перед коммерческим запуском требуется отдельная проверка обработки персональных данных и условий размещения.

## Анимации и skill

UI/UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill. Сохранённая дизайн-система — `design-system/overtake`, применённые изменения — `pages/website.md`.

Официальный Magic UI MCP `@magicuidesign/mcp@2.1.0` запускался через MCP SDK. Результаты вызовов — `references/magicui`. Компоненты скачаны из официального реестра. BlurFade — появление секций; BorderBeam — контур карточки; Motion — мягкое движение графики. CSS адаптация BorderBeam заменяет Tailwind-утилиты, сохраняя механику компонента. Источники: https://magicui.design/docs/mcp, https://magicui.design/docs/components/blur-fade, https://magicui.design/docs/components/border-beam. Уважает `prefers-reduced-motion`.

MCP является инструментом разработки и не попадает в клиентскую или серверную сборку. Конфигурация для запуска в другом MCP-клиенте — `mcp.example.json`.
